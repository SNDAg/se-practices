# JS Course Practice & CI/CD Project 🚀

A comprehensive JavaScript practice repository demonstrating modern software development principles, DevOps methodologies, and automated workflows.

---

## 📚 Topics Covered

This project was built as part of the hands-on curriculum, covering the following core modules:

1. **Linux and Shell** – Working with Linux environment, writing Shell commands, and scripting.
2. **Source Control and Git** – Version control best practices, branching strategies, and Pull Requests.
3. **Testing** – Writing unit tests in JavaScript to ensure code reliability.
4. **Open Source** – Understanding open-source principles and leveraging external packages.
5. **Dependency Management** – Managing project packages and scripts using `npm` and `package.json`.
6. **Agile Development & Mindset** – Agile workflows, iterative development, and continuous improvement.
7. **Code Review** – Standards for reviewing pull requests and maintaining high code quality.
8. **Observability** – Logging, monitoring, and inspecting application performance.
9. **Secure Coding** – Identifying vulnerabilities and implementing basic security safeguards.
10. **Containers** – Containerizing applications using Docker for consistent environments.
11. **DevOps & CI/CD** – Automating build, test, and deployment processes via GitHub Actions.

---

## 🛠️ Tech Stack & Tools

* **Language:** JavaScript (Node.js)
* **Package Manager:** npm
* **Version Control:** Git & GitHub
* **CI/CD:** GitHub Actions
* **Containerization:** Docker
